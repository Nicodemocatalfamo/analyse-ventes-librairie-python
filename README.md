
# Analyse des ventes d’une librairie — Python

Projet réalisé dans le cadre de ma **certification Data Analyst**.

## Présentation

Ce projet consiste à analyser les ventes d’une librairie à partir de données transactionnelles afin d’identifier les tendances principales et de mieux comprendre les comportements observés.

L’objectif est d’utiliser Python et différentes méthodes statistiques pour transformer les données en informations exploitables pour l’analyse métier.

## Démarche

Le projet comprend notamment :

- l’exploration et l’analyse des données ;
- l’étude des ventes et de leur évolution ;
- l’analyse des relations entre plusieurs variables ;
- l’étude de séries temporelles ;
- la réalisation d’analyses bivariées ;
- l’utilisation de tests statistiques ;
- l’interprétation des résultats obtenus.

## Compétences mises en œuvre

- Analyse exploratoire de données
- Analyse bivariée
- Analyse de séries temporelles
- Tests statistiques
- Interprétation de relations entre variables
- Analyse de données avec Python
- Restitution des résultats

## Contenu du dépôt

Le dépôt comprend :

- le notebook Python contenant l’analyse ;
- une présentation synthétisant la démarche et les résultats du projet.

## Ce que ce projet démontre

Ce projet montre ma capacité à analyser des données commerciales, identifier des relations entre différentes variables et utiliser des méthodes statistiques pour répondre à des problématiques métier.

Il illustre également ma capacité à interpréter l’évolution des données dans le temps et à restituer les conclusions d’une analyse.

**Outils :** Python · Analyse de données · Analyse bivariée · Séries temporelles · Tests statistiques
